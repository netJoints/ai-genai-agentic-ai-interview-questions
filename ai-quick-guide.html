Quick interview guide

AI in Plain English

How we moved from early AI and neural networks to Transformers, LLMs, RAG, and agentic AI—and why each step became necessary.

The one-minute story

AI is not new. The recent wave happened because neural networks learned from more data, GPUs made the math fast enough, Transformers handled context efficiently, and chat interfaces made the results easy to use.

Interview questions, in chronological order

1

Is AI new?

Answer

No. AI has existed since the 1950s. Earlier systems used rules, search, statistics, and expert knowledge. They were useful but often brittle when language or situations became messy.

Rules→Useful but brittle→Learn from data
2

What problem were researchers trying to solve with language?

Answer

People wanted computers to understand and produce natural language instead of requiring exact commands. Language is difficult because meaning depends on surrounding words, word order, tone, and real-world context.

Human language→Ambiguity + context→Language models
3

What is a neural network?

Answer

A neural network is a set of connected mathematical layers. During training, it adjusts learned numbers called weights so it gets better at recognizing patterns. Deep learning uses many such layers.

Examples→Layers + weights→Learned patterns
4

What is a GPU, and why is it important?

Answer

A GPU, or graphics processing unit, does many similar calculations in parallel. Neural networks use huge matrix calculations, so GPUs and other AI accelerators make training and inference much faster.

Matrix math→GPU: parallel work→Faster AI
5

What changed with “Attention Is All You Need”?

Answer

In 2017, the paper introduced the Transformer architecture. Its key idea, attention, lets a model weigh which parts of the input matter most to one another. A useful memory aid is “context is what you need,” but that is not the paper’s title.

Tokens→Attention→Relevant context
6

What is a Transformer?

Answer

A Transformer is a neural-network architecture built around attention. It learns relationships between tokens and can be trained efficiently in parallel. It is a foundation for many language models, not a chatbot or agent by itself.

Tokens→Transformer layers→Relationships + output
7

What is pretraining?

Answer

Pretraining is the first large learning stage. A model sees lots of text and practices predicting the next token. It learns language patterns and relationships that are stored in its weights.

Large text dataset→Predict next token→Base model
8

What is an LLM, and what does GPT mean?

Answer

An LLM is a large language model. The first GPT paper appeared in 2018; later scaling, including GPT-3 in 2020, improved the model’s ability to perform many language tasks. GPT means Generative Pre-trained Transformer: it generates output, is pretrained on large datasets, and uses the Transformer architecture. GPT is one family of LLMs; not every LLM is GPT.

Prompt→Tokens→GPT→Generated tokens
9

What is a token?

Answer

A token is a small piece of text: a word, part of a word, punctuation, or another tokenizer-defined piece. The model converts tokens into numbers and predicts the next token. Tokens are not exactly words, and token counts affect context limits, speed, and cost.

Text→Tokenizer→Token IDs→Model input
10

What is inference?

Answer

Inference is using a trained model to produce an output from an input. Training changes weights; inference uses them. A model answering a prompt is doing inference.

Trained weights+Prompt→Inference→Answer
11

What is GenAI?

Answer

Generative AI creates new output from a prompt or other input. LLMs generate text and code, while other GenAI systems generate images, audio, video, or structured data.

Prompt→Generative model→Text / code / image / audio
12

Why did ChatGPT matter?

Answer

In 2022, ChatGPT made large language models easy for everyday people to use through conversation. It was not the first natural-language AI tool or the first GPT interface; it made instruction-following, multi-turn conversation, and useful generation feel accessible in one product.

Person→Chat interface→Instruction-tuned model→Response
13

Why was RAG needed?

Answer

LLMs have a training cutoff and do not automatically know an organization’s private or current information. The term retrieval-augmented generation (RAG) was formalized in a 2020 paper. RAG searches relevant sources at question time, puts selected passages into the prompt, and asks the LLM to answer using that context.

question → retrieve → prompt → grounded answer

Question→Retrieve sources→Context→LLM answer
14

What are embeddings and a vector database?

Answer

An embedding represents text as numbers so similar meanings are mathematically close. A vector database stores those embeddings and finds nearby passages. In RAG, the vector database is the search memory; the LLM is the language generator.

Documents + question→Embeddings→Vector search→Relevant passages
15

What is agentic AI?

Answer

An agentic AI system can take a goal, break it into steps, use tools, inspect results, and continue until it reaches a stopping point. Reliable agents still need permissions, guardrails, logging, evaluation, and human approval for risky actions.

Goal→Plan→Use tools→Observe↺
16

What important ideas are easy to miss?

Answer
  • Instruction tuning and alignment help a base model follow instructions and safety rules.
  • Grounding and evaluation matter because a fluent answer is not automatically correct.
  • Multimodal AI combines text with images, audio, video, code, and tools.
Model output→Grounding + evaluation→Trusted action

How to read the diagrams

  • Neural networks learn numerical patterns from examples instead of depending only on hand-written rules.
  • GPUs are a speed enabler. They are not an AI model; they accelerate the large parallel calculations used by training and inference.
  • Transformers use attention to decide which tokens and pieces of context matter most to one another.
  • LLMs are large language models. GPT is one LLM family: Generative Pre-trained Transformer.
  • GenAI creates new output. ChatGPT made conversational use of an LLM accessible to a broad audience; it was not the first natural-language AI tool.
  • RAG retrieves information at question time and supplies it to the LLM. It normally does not retrain the model.
  • A vector database stores embeddings so a system can find passages with similar meaning.
  • Agentic AI adds a controlled loop around a model so it can complete a goal using tools and multiple steps.

One-line mental model

LLM = generates language
RAG = supplies better context
Agent = uses the model in a tool-using loop
The simplest mental model

An LLM is a powerful pattern generator. RAG supplies better and more current context. An agent adds a loop so the model can use tools and complete multi-step work. All three still need good data, security, testing, and human judgment.
